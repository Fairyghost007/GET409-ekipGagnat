# ekipGagnat

## Nom du projet
**ekipGagnat**

## Problème détecté
Les étudiants passent beaucoup de temps à chercher des ressources pédagogiques, sans être sûrs de leur fiabilité ni de leur adéquation avec leur programme d’études.

## Réponse apportée
Nous proposons une solution en éducation numérique qui aide les étudiants à identifier rapidement des ressources pédagogiques fiables, adaptées à leur programme, et facilement accessibles depuis leur smartphone.
